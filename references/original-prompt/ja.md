# XXD Panel 082 原文プロンプト · 日本語読解訳

アップロードした写真を1枚ずつ、独立した上質なデザインポスターにしてください。複数画像を連結せず、各写真を個別に出力します。全体は3:4の縦構図とし、上下2領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在感のある質感、自然な光と影、元の色彩の雰囲気を保ちます。調整は控えめで上質なカラーグレーディングに限り、アート雑誌、独立系出版物、展覧会写真のような質感にします。画角に合わせて周囲の環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、改変したりしてはいけません。

下半分では、写真から最も識別性の高い**主体、輪郭、構造、姿勢、物語上の関係**を抽出し、**Naïve Watercolor + Wonky + Isometric** の融合スタイルとして再構成します。写真を完全に描き写さず、最重要の同一性と視覚的比喩だけを残します。複雑な場面を少数の水彩色面と一つの明確な中心人物へ圧縮し、元の対象がひと目で分かる一方、再設計された童心、空間性、芸術性を備えさせます。

まず**大面積の不規則な水彩色面**で基礎構図を作ります。色面には自然な水跡、粒子、濃淡、紙の透け、わずかなずれを持たせ、自由に広がる柔らかな地形や抽象的舞台のようにします。中心主体は **Isometric / 2.5D の幾何学的立体論理**によって色面から「飛び出し」、軸測投影、重なる平面、幾何学的切面、前後の遮蔽、わずかな高低差で立体感を作ります。主体の一部は色面の境界を越えてもよく、二次元水彩と三次元の錯覚を自然に交差させ、「平面の色面が小さな立体世界を持ち上げる」視覚関係を形成します。

主体造形には **Naïve + Wonky** の素朴さを保ちます。比率は適度に誇張でき、構造には軽い非対称や手作業の誤差を含め、輪郭は緩く、線幅が不均一で、わずかに震える手描き線にします。ただし Isometric の基本視点、構造方向、空間関係は明確でなければならず、論理のないカートゥーンへ歪ませてはいけません。全体に**幾何学秩序と無邪気な手描きが共存する**対比を示します。

構図では**主体の着地点、色面比率、立体方向、正負形、大きな余白**を重視します。主体を機械的に中央へ置く必要はなく、元写真の方向に応じて偏らせたり、上げたり、下げたり、部分的に裁ち落としたりできます。水彩色面は背景だけでなく、地形、空気、影、物語空間も担います。複雑な環境は積極的に削除し、中心テーマを強める少数の形だけを残して、主体を真に唯一の視覚中心にします。

上の写真から**最も明るく、鮮やかで、生命力のある色**を選んで再調整し、均等には採色しません。元写真の色を、澄んだ青、アクア、若草色、暖黄、コーラルオレンジ、桃色、柔らかな紫など、鮮やかで優しい水彩関係へ変換します。大量の清潔な暖白、または元写真の総合色温度に調和するごく淡い背景色を呼吸空間にします。水彩の下層は柔らかく透明でもよく、立体主体の主要色面はやや実在感と鮮明さを強め、中心人物を背景から自然に浮かび上がらせます。濁った灰色、沈んだ色、過度なモランディ調、蛍光色、安価なキャンディー感は避けます。

文字は少量だけ介入させ、写真の主体、動作、場所、感情、比喩から短い文言を自由に生成し、言語は限定しません。**細く丸みがあり、わずかな手書きのずれと緩い組版感を持つエディトリアル書体**を使い、絵本の親しみやすさと独立系アート出版物の抑制を両立します。文字は水彩色面の縁、Isometric 軸、主体の近く、大きな余白に自然に置き、二次元の色面と立体主体とともに図文のリズムを作ります。

全体は、**大きな余白、不規則な水彩色域、素朴な手描き輪郭、Isometric の立体的主役、鮮やかで癒やしのある配色**が一体となった上質な絵本ポスターの気質にします。中心主体が柔らかな水彩平面から突然空間を得て、立ち上がり、紙面から飛び出すように見せます。純粋に平面的な児童イラストにも、写実的な3Dモデルにもしてはいけません。
